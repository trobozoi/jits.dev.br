# jits.dev.br

Site institucional da **JITS** — Soluções inteligentes para a sua empresa.

Página estática (HTML + CSS), publicada pelo GitHub Pages no domínio [jits.dev.br](https://jits.dev.br).

## Arquivos

- `index.html` — o site completo
- `favicon.svg` — ícone da aba do navegador
- `CNAME` — domínio personalizado do GitHub Pages

## Como editar

Edite o `index.html`, faça commit e push na branch `main`. O GitHub Pages publica sozinho em alguns minutos.
